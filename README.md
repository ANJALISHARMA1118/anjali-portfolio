# Anjali Sharma — Developer Portfolio

A responsive personal portfolio built with HTML, CSS, and vanilla JavaScript. It includes Java/backend projects, WordPress experience and website projects, technical skills, education, and contact links.

## Run locally
1. Extract the ZIP file.
2. Open the `anjali-portfolio` folder.
3. Double-click `index.html`, or open the folder in VS Code and use Live Server.

No Node.js, build step, or package installation is required.
